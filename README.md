# Gestion des tâches (Python)

Application console simple pour gérer des tâches quotidiennes.

## Fonctionnalités
- Ajouter une tâche
- Afficher les tâches
- Rechercher une tâche par mot-clé
- Quitter

## Exécution
Ouvrir main.py dans VS Code puis cliquer sur « Run Python File ».
